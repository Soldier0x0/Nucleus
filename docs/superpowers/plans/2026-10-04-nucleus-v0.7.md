# Nucleus v0.7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship one v0.7 release that removes leftover demo money, makes every home board a two-column circle, and adds public transport, location-once weather, money and vehicle comparisons, cycle history, a photo gallery, and a privacy screen.

**Architecture:** Keep the existing local database and the v0.6.3 removers. `withoutSampleData` also drops fuel and service mirror notes whose vehicle name is gone, and puts the pre-demo budget back. Home paging is one circle of every preset. Travel, money, cycle, and gallery behavior are pure functions in `frontend/src/core`, then thin screens. Four groups, one version, one implementation pull request after this plan is approved.

**Tech Stack:** Expo SDK 57, React Native 0.86, TypeScript, `node:test` with `frontend/src/core/test-loader.mjs`, `expo-location` for one coarse read.

## Global Constraints

- One release, v0.7. Do not rewrite v0.6, v0.6.1, v0.6.2, or v0.6.3 notes. Do not pre-seed the next version.
- The user can be anyone. Do not write copy that assumes she.
- No foods, remedies, mood or arousal forecasts, spoken buddy, points, or guilt words (overdue, missed, behind, late, fail).
- Tests must use an upgraded database that has no sampleIds, and a real icon alias change. A fresh withSampleData test is not enough.
- Install over the current app. Do not uninstall.
- User's real data that must survive: income 2000, expense 177, expense 100, and their own naked bike. Demo leftovers must go: Activa fuel and service money copies (notes like "Activa · 5.6 L" and "Activa · Engine oil"), the 45000 demo budget, and unnamed "Two Vehicle expenses on a date" lines.

Every task includes these constraints. `frontend/src/core/v07.test.ts` must not import `withSampleData`.

```ts
export const BOARD_CIRCLE: HomePresetId[] = ["custom", "money", "travel", "home", "desk", "workshop", "adhd"];

export function swipeScreens(preset: HomePresetId): HomePresetId[] {
  switch (preset) {
    case "custom":
    case "money":
    case "travel":
    case "home":
    case "desk":
    case "workshop":
    case "adhd":
      return BOARD_CIRCLE;
    default: {
      const never: never = preset;
      return never;
    }
  }
}

export function swipeStartIndex(preset: HomePresetId): number {
  const index = swipeScreens(preset).indexOf(preset);
  return index < 0 ? 0 : index;
}

export function swipeWrap(index: number, count: number): number {
  if (count <= 0) return 0;
  return ((index % count) + count) % count;
}

export function swipePages(preset: HomePresetId): HomePresetId[] {
  const circle = swipeScreens(preset);
  const first = circle[0];
  if (!first) return circle;
  return [...circle, first];
}
```

```ts
export function rememberPeriod(days: CycleDay[], start: string, end: string): CycleDay[] {
  if (!DATE.test(start) || !DATE.test(end) || end < start) return days;
  const next = days.map((day) => ({ ...day }));
  let cursor = start;
  while (cursor <= end) {
    const existing = next.find((day) => day.date === cursor);
    if (existing) {
      existing.bleeding = "flow";
      if (cursor === end) existing.ended = true;
    } else {
      next.push({ id: `period-${cursor}`, date: cursor, bleeding: "flow", ended: cursor === end ? true : undefined });
    }
    cursor = addDays(cursor, 1);
  }
  return next;
}
```
